Enviar un mensaje

cURL

curl -X POST \
  https://tu-gateway/api/v1/send-message \
  -H 'x-api-key: TU_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"phone":"58412...","message":"Hola"}'

Node.js

const response = await fetch(
  'https://tu-gateway/api/v1/send-message',
  {
    method: 'POST',
    headers: {
      'x-api-key': process.env.WA_API_KEY,
      'content-type': 'application/json'
    },
    body: JSON.stringify({
      phone: '58412...',
      message: 'Hola 👋'
    })
  }
);

Preguntas frecuentes

Empieza con claridad

¿Cómo conecto mi WhatsApp?+

Después de activar tu plan, abre el dashboard y escanea el código QR con WhatsApp en tu teléfono, desde Dispositivos vinculados.

¿Puedo integrar la API con mi aplicación?+

Sí. Los ejemplos de cURL y Node.js muestran el envío de mensajes con una solicitud HTTP autenticada.

¿Cómo puedo pagar?+

Al registrarte podrás consultar los métodos disponibles para tu cuenta, incluidos Pago Móvil, Facebank/Pipol Pay, Binance Pay y PayPal.
